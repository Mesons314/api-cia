# API-CIA Frontend

Professional React + TypeScript + Vite + Tailwind CSS frontend for **API-CIA (API Change Impact Analyzer)**.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Configure backend URL** in `.env`:
   ```bash
   VITE_API_BASE_URL=http://localhost:8080
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Build production bundle**:
   ```bash
   npm run build
   ```
